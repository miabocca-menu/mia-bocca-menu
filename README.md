# Mia Bocca メニュー & アレルギー情報

Mia Bocca 北海道イタリアンバル さいたま新都心店の、多言語メニューとアレルギー情報のページです。
日本語・English・繁體中文・简体中文・한국어 の5言語で表示できます。

**公開URL：** https://miabocca-menu.github.io/mia-bocca-menu/

<img src="qr/qr.png" alt="公開URLのQRコード" width="200">

## 機能
- 料理をタップすると、特定原材料8品目（えび・かに・くるみ・小麦・そば・卵・乳・落花生）の使用状況（● 使用 / ▲ 製造ライン共有・接触 / — 不使用）を表示
- 「避けたい食材」を選ぶと、その食材を使う料理を薄く表示（▲ も対象にするか選択可）
- アレルギー一覧表
- `?lang=ja` / `en` / `zh-Hant` / `zh-Hans` / `ko` で最初に表示する言語を指定可能

## 更新方法
メニューとアレルギー情報は `index.html` の `<script>` 内にあります。
- `M`：料理一覧。`[番号, カテゴリ, 写真ファイル名, アレルゲン8文字, 価格, 日本語名, 英語名, 繁体字名, 簡体字名]`
  - アレルゲン8文字の順番：えび・かに・くるみ・小麦・そば・卵・乳・落花生（`o`=使用、`t`=製造ライン共有・接触、`-`=不使用、`null`=表に記載なし）
- `KO`：韓国語の料理名（`M` と同じ順番）
- `EX`：表のみに載せる品目
- 写真は `img/` に置きます

変更後に push すると、数分で公開ページに反映されます。
```
git add .
git commit -m "メニュー更新"
git push
```
